# Robotics AI

**[Try Robotics AI →](https://roboticsai.streamlit.app/)** **https://roboticsai.streamlit.app/**

Robotics AI is a web-based **Retrieval-Augmented Generation (RAG)** AI assistant designed to help with robotics engineering projects.

It can assist with:
- **Brainstorming** and developing robotics ideas
- **Debugging** hardware and software
- **Engineering calculations** and problem solving
- **Technical research** and project development
- **Understanding robotics concepts** and documentation

Built to make robotics engineering more accessible by combining AI with relevant technical knowledge.
